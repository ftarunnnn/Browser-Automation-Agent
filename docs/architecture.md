# WebPilot AI — System Architecture & Design

WebPilot AI is an autonomous, production-grade AI Browser Automation Agent designed to transform high-level natural language instructions into structured, verified browser actions using Playwright and LLM reasoning engines.

## 2. Core Execution Loop

WebPilot AI enforces an explicit, state-checked loop for every browser step:

1. **OBSERVE**: `BrowserInspector` evaluates page DOM, interactive elements, headings, forms, tables, and accessibility attributes.
2. **UNDERSTAND**: `TaskPlanner` processes the user's objective alongside current page state and action history.
3. **PLAN**: The LLM engine generates the next structured tool call (`open_url`, `click`, `type`, `select`, `scroll`, `press`, `extract_text`, `download`).
4. **SAFETY CHECK**: `SafetyPolicy` & `ApprovalManager` check if the action is sensitive (purchases, payments, emails, account deletion). If sensitive, loop pauses and prompts user for approval.
5. **ACT**: `ToolExecutor` executes Playwright browser action with timeout and identical action loop protection.
6. **VERIFY**: `ActionResultVerifier` validates whether expected state change occurred (URL change, element mutation, text presence).
7. **RECOVER**: If action failed or verification failed, `FailureRecoveryEngine` computes alternative selector matching, popup dismissal, or scroll fallback.

## 3. Database Persistence Model

WebPilot AI stores state using Async SQLAlchemy supporting SQLite & PostgreSQL:
- **`tasks`**: Task metadata, status (`IDLE`, `PLANNING`, `RUNNING`, `WAITING_FOR_APPROVAL`, `RECOVERING`, `COMPLETED`, `FAILED`, `STOPPED`), current URL, error details.
- **`task_steps`**: Sequential plan milestones generated by AI Planner.
- **`agent_actions`**: Logged browser tool calls, parameters, execution times, and status.
- **`task_results`**: Structured JSON extracted results and page text excerpts.
- **`screenshots`**: Captured Playwright page screenshots per step.
- **`approvals`**: Pending human approval requests for sensitive operations.
